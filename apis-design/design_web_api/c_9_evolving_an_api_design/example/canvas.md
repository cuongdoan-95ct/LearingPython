# API Goals Canvas Example: Library Management API

This API Goals Canvas outlines the objectives for a Library Management API, designed to help library patrons and staff manage book borrowing and availability.  

| Who's (Who) | What's (What) | How's (How) | Inputs (Source) | Outputs (Usage) | Goals |
|-------------|---------------|-------------|-----------------|-----------------|-------|
| None | None | None | None | None | None |
| None | None | None | None | None | None |
| None | None | None | None | None | None |

## Notes:
- **Who's**: Identifies the users of the API, such as library patrons (end-users) or staff (internal users).
- **What's**: Describes the specific goal the user wants to achieve.
- **How's**: Explains the actions the user takes to achieve the goal.
- **Inputs (Source)**: Specifies the data provided to the API and its source.
- **Outputs (Usage)**: Details the API’s response and how it will be used by the consumer.
- **Goals**: Detail for goals

This canvas helps ensure the API is designed with the consumer’s perspective in mind, avoiding provider-specific jargon or implementation details.
